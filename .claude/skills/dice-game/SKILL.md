# 骰子游戏

用 `my-first-mcp` 提供的 `roll_dice` 工具掷骰子，并按下面的规则判定输赢。

## 铁律

- **必须调用 `roll_dice` 工具**得到点数，绝对不能自己编一个随机数。
- 如果 `roll_dice` 工具不可用，直接告诉用户"my-first-mcp 没有连接，请用 `/mcp` 检查"，不要假装掷骰子。

## 玩法

### 猜大小（默认）

- 骰子：一颗六面骰，调用 `roll_dice`（`sides` 用默认值 6）。
- 用户猜"大"或"小"：
  - 1–3 为**小**，4–6 为**大**。
  - 猜对算赢，猜错算输。

### 猜点数

- 用户猜一个 1–6 的具体点数。
- 完全猜中算**大赢**，否则算输。
- 用户可以指定别的面数（如"20 面骰"），此时把 `sides` 传给 `roll_dice`，猜点数规则不变；猜大小时以 `sides / 2` 为界（点数 ≤ `sides / 2` 为小，其余为大）。

### 用户没说清楚怎么玩

先问一句：猜大小还是猜点数？以及猜什么。不要替用户做选择。

## 回复格式

每一局按这个格式回复：

```
🎲 你猜：<用户的猜测>
🎲 骰子：<点数>
结果：<赢 🎉 / 输 😢 / 大赢 🏆>
```

之后加一句简短的点评（一句话即可，可以幽默一点），然后问用户要不要再来一局。

## 记分

同一次对话里累计战绩。每局结束后在末尾附上一行：

```
战绩：X 胜 Y 负
```

"大赢"按一胜计算。用户说"重新开始"或"清零"时把战绩归零。
